# SpeedRead PWA

Минималистичное скорочтение RSVP для Windows и iPhone. Книга показывается по одному слову, красная буква фиксируется между двумя штрихами.

**Открыть приложение: https://sandinoff.github.io/speedreadpwa/**

## Установка

- **iPhone:** открыть адрес в Safari → «Поделиться» → «На экран Домой» → «Добавить». Затем запустить приложение с появившейся иконки.
- **Windows:** открыть адрес в Chrome или Edge → установить приложение кнопкой в браузере или через меню SpeedRead.
- После появления «Готово к чтению без интернета» можно пользоваться сохранёнными книгами офлайн.

## Возможности

- EPUB без DRM в порядке OPF spine.
- Скорость 1–750 слов/мин, ползунок, кнопки ±10 и точный ввод.
- Паузы по пунктуации и длине слов; оценка оставшегося времени в часах и минутах.
- Дефисы и тире перед словом показываются вместе с ним.
- Двойное нажатие на слово открывает полный текст в том же окне. Большие книги отображаются страницами без загрузки всей книги в интерфейс.
- Сохранение позиции, темы, скорости и достижений локально; возобновление с начала предложения.
- Светлая и полностью чёрная ночная тема. Интерфейс скрывается через 5 секунд чтения, нажатие возвращает паузу.
- Библиотека с прокруткой, перенос JSON и резервная копия.

## Книги и конфиденциальность

Книги и прогресс хранятся в IndexedDB вашего браузера, не в GitHub. EPUB обрабатываются на устройстве. Аккаунт, платные API, аналитика и внешние библиотеки не используются.

На каждом устройстве и адресе сайта отдельная библиотека. После очистки данных браузера библиотека может исчезнуть; сохраняйте резервные копии через меню. Одновременная синхронизация между устройствами не предусмотрена.

## Перенос из Python-версии

Закройте Python-версию. На Windows откройте `%LOCALAPPDATA%\SpeedRead`. В PWA выберите «Перенести книги и прогресс · JSON», затем выберите `state.json` и файлы книг `<id>.json`. Подтвердите перенос статистики. Файлы исходной версии не изменяются.

Для переноса на iPhone можно сначала импортировать эти данные в PWA на Windows по **этому же HTTPS-адресу**, сохранить резервную копию и импортировать её на iPhone. Автоматической синхронизации нет.

## Локальная разработка

`python -m http.server 8765 --bind 127.0.0.1` из корня репозитория, затем открыть `http://localhost:8765/`. Не открывайте `index.html` через `file://`: для PWA нужен localhost или HTTPS. При изменении оболочки повышайте версию кэша в `sw.js`; после загрузки обновления перезапустите страницу.

Для публикации: GitHub Pages → Deploy from a branch → main → / (root). Все URL ресурсов относительные, приложение поддерживает размещение в `/speedreadpwa/`.

## Проверки и ограничения

При локальной проверке выполнены 14 проверок движка/EPUB/хранилища и 12 сценариев интерфейса в Chrome на Windows, в том числе книга на 200 003 слова и мобильная компоновка 390×844. Проверена перезагрузка сохранённой книги при остановленном локальном сервере.

Нужен современный браузер с IndexedDB, Service Worker и `DecompressionStream('deflate-raw')`. На физическом iPhone приложение ещё не проверено. EPUB: до 100 МБ, распакованные данные до 160 МБ, без DRM, ZIP64 и многотомных архивов. UTF-8; нестандартная/повреждённая разметка может не импортироваться. Исходная вёрстка и абзацы EPUB не сохраняются. Границы предложений определяются по пунктуации, сокращения с точками могут определяться неточно.

Исходная Python/Tkinter-версия развивается отдельно и в этот репозиторий не включена. Тестовые книги, пользовательская библиотека и статистика не публикуются.
